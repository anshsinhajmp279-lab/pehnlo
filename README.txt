PEHNLO Prototype (v0.1)

WHAT THIS IS
- Mobile-friendly customer shopping prototype.
- Includes sample products, category filters, search, cart, profile fields, and local demo orders.
- Cart/profile/demo orders are stored only in the current browser on this device.
- No live backend, real shop accounts, payment gateway, delivery partner system, notifications, or real inventory is connected.

HOW TO RUN
1. Extract pehnlo_prototype.zip.
2. Open index.html in a modern browser (Chrome recommended).
3. On Android, you can transfer index.html to the phone and open it in Chrome, or host the folder on a static website host.
4. This is not yet an installable Play Store app. To publish, it needs production backend/security, legal/privacy setup, testing, Android packaging (AAB), and Google Play Console submission.
